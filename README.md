# TSI API — Primeira atividade

Primeira API em **Node.js, Express e TypeScript**, criada na disciplina de API e Banco de Dados (Tecnologia em Sistemas Inteligentes, Fatec Shunji Nishimura).

## Rotas

| Método | Rota | Descrição |
|---|---|---|
| GET | `/` | Mensagem de boas-vindas |
| GET | `/saudacao/:nome` | Saudação personalizada |

## Como executar

```bash
npm install
npm run dev
```

O servidor sobe em `http://localhost:3000`.
